# Вгадай хід гросмейстера

MVP гри: позиції з реальних партій, гравець вгадує хід, який зробив гросмейстер.

## Як це працює

```
data/games/*.pgn ──► pipeline/build.py (Stockfish) ──► web/public/data/puzzles.json ──► web/ (React, статика)
```

- **Правильна відповідь** — хід із партії (PGN). Рушій у браузері не потрібен.
- **Оцінки рахуються офлайн.** Для кожної відібраної позиції Stockfish оцінює *всі* легальні ходи,
  тому будь-який хід користувача оцінюється без бекенду.
- **Нарахування очок** (`web/src/scoring.ts`):
  - 🟩 хід гросмейстера — `100 × складність`;
  - 🟨 інший хід, що втрачає ≤ 30 сп відносно найкращого, — `50 × складність`
    («сильний хід, але Карлсен зіграв інакше»);
  - ⬛ решта — 0, показується реальний хід.
- **Відбір позицій** (`pipeline/build.py`): пропускаються перші 10 ходів (теорія), вимушені
  розміни та вже вирішені позиції (|оцінка| ≥ 7 пішаків). Пріоритет — позиції, де гросмейстер
  зіграв сильно, сильних ходів мало, а на малій глибині (depth 6) хід неочевидний.
  Та сама неочевидність визначає складність ★–★★★.
- **Пояснення** — лише головний варіант рушія. Текстових пояснень від LLM навмисно немає.

## Меню

- **Обрати гросмейстера** — список чемпіонів, сторінка з фото, біо, «Як грав» і «Сильні сторони»
  (тексти — `web/src/content/gms.ts`). Обраний гросмейстер показується великою кнопкою в меню.
- **Випадкова партія** — серед партій обраного гросмейстера або з усієї колекції.
- **Обрати партію** — від найвизначніших; перед стартом превʼю «чим важлива» (`web/src/content/games.ts`).
- **Хід дня**.
- **Налаштування** — 5 тем застосунку, 10 кольорів дошки (на зразок Lichess / Chess.com), мова (uk / en), темп, звук,
  показ оцінки рушія, пропуск дебюту (перші 2 ходи програються на дошці по 0,5 с), скидання статистики.

## Режими

- **Партія** — 10 ключових позицій однієї партії, у кінці «Ти зіграв як Фішер на X%» + emoji-сітка.
- **Хід дня** — одна позиція на день, однакова для всіх; хто грав, розкривається після відповіді.
- **GM-індекс** — статистика вгадувань за кожним гросмейстером (localStorage).

## Запуск

```bash
# фронтенд
cd web && npm install && npm run dev      # npm test, npm run build

# перебудова позицій (потрібен stockfish, напр. apt install stockfish)
python -m venv .venv && .venv/bin/pip install -r pipeline/requirements.txt
.venv/bin/python pipeline/build.py --depth 16             # усі партії
.venv/bin/python pipeline/build.py --only tal-larsen-1965-g10
```

## Додати партію

1. Взяти PGN (наприклад, архіви гравців з pgnmentor.com) і витягти партію:
   ```bash
   python pipeline/extract.py Carlsen.pgn --find Carlsen Anand 2013   # знайти індекс
   python pipeline/extract.py Carlsen.pgn 1585 carlsen-anand-2013-g5
   ```
2. Додати запис у `data/games.json` (`hero` — за кого грає користувач).
3. Перезапустити `pipeline/build.py`.

## Обмеження MVP

- Перетворення пішака — завжди у ферзя (гросмейстерське недоперетворення не вгадати).
- Часу на обдумування ходу немає: `%clk` є лише в сучасних PGN.
- Статистика лише локальна (без акаунтів і глобального рейтингу).
- Глибина 16 — компроміс; на «good»-порогу 30 сп можливий шум оцінки.
- Джерело PGN: pgnmentor.com. Перед публічним запуском перевірити умови використання бази
  та імен гравців у маркетингу.
